# Miro Group Work Grader v0.1

Moodle等から出した評定Excelを読み込み、MiroグループワークのWeek別点数を付けるための小型アプリです。

## 前提のExcel

既存列は次の想定です。

- A: Name
- B: 氏名
- C: IDナンバ
- D: 所属
- E: メールアドレス
- F: グループワーク (Miro) (実データ)
- G: その他の既存列

H列以降に `Week 1`, `Week 2`, ... を自動追加します。
F列には、Week別素点から換算したMiro最終評定を数値で入れます。

## 起動方法（Mac）

1. このフォルダを任意の場所に置きます。
2. `start.command` をダブルクリックします。
3. ブラウザでアプリが開きます。
4. 評定Excel（.xlsx）を選びます。

初回だけ、Streamlit等の必要パッケージを `uv` が準備します。

macOSが `start.command` の実行を止める場合は、右クリック →「開く」を一度使ってください。

## 採点方法

1. 「今回のWeek」を選びます。
2. グループの学生を複数選択します（氏名・学籍番号下4桁で検索可）。
3. 点数を入力し、「選択した学生に入力」を押します。
4. 小さい整数満点（例: 2点満点）の場合は、0点・1点・2点のクイックボタンも出ます。
5. 採点が終わったら「更新済みExcelをダウンロード」します。
6. 次回は、その更新版Excelを読み込んで続けます。

## 配点

サイドバーで以下を変更できます。

- Week数（初期値14）
- 1回あたりの満点（初期値2）
- Miro最終配点（初期値20/100）
- 最終点の小数桁（初期値1）
- 採点対象Week

飛ばしたWeekは「採点対象Week」から外してください。採点対象外のWeekは最終点の分母に入りません。

F列の計算は次の通りです。

`採点対象Weekの素点合計 ÷ 採点対象Weekの満点合計 × Miro最終配点`

## データの保存

- Week別点数はH列以降に残ります。
- アプリ設定はExcel内の非表示シート `Miro_Settings` に保存します。
- 元のExcelは上書きしません。
